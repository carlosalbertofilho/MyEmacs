# Modern Layouts
- **Modern Layouts:** Prefer CSS Grid, modern Flexbox, CSS variables, container queries, `:has()`, and native anchor positioning. Avoid outdated float/bootstrap grids.
- **Premium Aesthetics:** Propose dark modes, glassmorphism (backdrop filters), smooth transitions, HSL color palettes, and micro-animations. Avoid default colors or plain designs.
- **No Placeholders:** Propose complete, functional markup and code. Never use "lorem ipsum" or dummy images without generating actual content.
