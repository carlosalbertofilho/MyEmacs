** vterm
- *Tipo:* Comando Interativo
- *Assinatura:* =(vterm . [Arg list not available until function definition is loaded.])=

#+begin_src text
Create an interactive Vterm buffer.
Start a new Vterm session, or switch to an already active
session.  Return the buffer selected (or created).

With a nonnumeric prefix arg, create a new session.

With a string prefix arg, create a new session with arg as buffer name.

With a numeric prefix arg (as in `C-u 42 M-x vterm RET'), switch
to the session with that number, or create it if it doesn't
already exist.

The buffer name used for Vterm sessions is determined by the
value of `vterm-buffer-name'.

** eshell/git (override custom)
- *Local:* =lisp/custom-term.el=
- *Função:* =eshell/git=

Handler nativo do Eshell que redireciona o comando =git log= para o
buffer gráfico do Magit em vez do stdout em texto puro.

- =git log= ou =git lg= → abre =magit-log-head= com os argumentos
  =("-20" "--graph" "--oneline")=, mostrando árvore e texto coloridos.
- Qualquer outro comando =git= (=git status=, =git pull=, etc.) delega
  para o binário real via =eshell-plain-command=, preservando o
  comportamento CLI normal.

```elisp
(defun eshell/git (&rest args)
  (if (or (null args)
          (and (stringp (car args)) (member (car args) '("log" "lg"))))
      (progn (magit-log-head '("-20" "--graph" "--oneline")) nil)
    (eshell-plain-command "git" args)))
```

O mecanismo de dispatch do Eshell resolve automaticamente =git= para
=eshell/git= (mesmo padrão de =eshell/ls=, =eshell/pwd=, etc.), sem
precisar de alias.

** Devenv no prompt (custom)

- *Local:* =lisp/custom-term.el=
- *Funções:* =+carlos/eshell-devenv-env-p=, =+carlos/eshell-devenv-toolchain=

O prompt =+carlos/eshell-starship-prompt= exibe também a presença do
=devenv= quando ativo (via =.envrc=/direnv ou =devenv shell=):

- Detecta o devenv pela variável de ambiente =DEVENV_ROOT= (só existe
  com o devenv ativo) e mostra =🔗 nome-do-projeto= (o basename do
  diretório do devenv).
- Coleta a *toolchain ativa* a partir dos env traps exportados pelo
  devenv, exibindo-os entre parênteses:
  - =GOROOT=/=GOPATH= → =go=
  - =NIX_PYTHONPATH=/=PYTHONPATH= → =python=
  - =RUSTFLAGS=/=RUSTDOCFLAGS= → =rust=
  - =CC= → =c=

Exemplo de prompt com o devenv ativo:
=🔗 CommonCore (go python c)=

Fora do devenv (sem =DEVENV_ROOT=), a exibição é uma no-op.

** Popper como aside esquerdo (custom)

- *Local:* =lisp/custom-term.el=
- *Funções:* =+carlos/popper-display-popup-at-left=,
  =+carlos/popper-select-popup-at-left=

O =popper= continua gerenciando os popups (=C-`= toggle,
=M-`= cycle, =C-M-`= toggle-type), mas exibe-os como um *aside*
lateral esquerdo em vez do fundo da tela:

- =popper-display-function= aponta para
  =+carlos/popper-select-popup-at-left=.
- A função usa =display-buffer-in-side-window= com
  =(side . left)= e =(window-width . 0.45)= (≈45% da frame).
- Deixar o eshell/vterm à *esquerda* evita colisão com o
  =dirvish-aside=, que ocupa a *direita* — permitindo usar ambos
  simultaneamente.
