* Dired & Dirvish Configuration Analysis

** Dired Core Switches & TRAMP Safety

Doom uses GNU ~ls~ switches when available and falls back safely over remote TRAMP connections or non-GNU platforms:

#+begin_src elisp
(let ((args (list "-ahl" "-v" "--group-directories-first")))
  (when (featurep :system 'bsd)
    (if-let* ((gls (executable-find "gls")))
        (setq insert-directory-program gls)
      (setq args (list (car args)))))
  (setq dired-listing-switches (string-join args " "))

  ;; Fixes #1703: dired over TRAMP displays a blank screen when -v or --group-directories-first is used
  (add-hook! 'dired-mode-hook
    (defun +dired-disable-gnu-ls-flags-maybe-h ()
      (when (or (file-remote-p default-directory)
                (and (boundp 'ls-lisp-use-insert-directory-program)
                     (not ls-lisp-use-insert-directory-program)))
        (setq-local dired-actual-switches (car args))))))
#+end_src

*Key Takeaways:*
- Switches used: ~-ahl -v --group-directories-first~.
- ~-h~: Human-readable file sizes (KB, MB, GB).
- ~-a~: Include hidden files (dotfiles).
- ~-v~: Natural version sorting (file1, file2, file10 instead of file1, file10, file2).
- ~--group-directories-first~: Directories appear before regular files.
- Remote/TRAMP fallback: Overrides ~dired-actual-switches~ to ~-ahl~ (first argument only) to prevent TRAMP parse failures.

** Dirvish Attributes & Icon Display

Doom overrides standard Dired with Dirvish and dynamically builds ~dirvish-attributes~ based on active module flags:

#+begin_src elisp
(use-package! dirvish
  :config
  (dirvish-override-dired-mode)
  
  ;; Base attributes
  (setq dirvish-attributes '(file-size)
        dirvish-mode-line-format '(:left (sort file-time symlink) :right (omit yank index)))
        
  ;; VC integration
  (when (modulep! :ui vc-gutter)
    (when (or (daemonp) (display-graphic-p))
      (push 'vc-state dirvish-attributes)))
      
  ;; Icon & Subtree integration
  (when (modulep! +icons)
    (setq dirvish-subtree-always-show-state t)
    (cl-callf append dirvish-attributes '(nerd-icons subtree-state))))
#+end_src

*Attribute Stack in Full UI:*
- ~nerd-icons~: Displays file/folder type icons using Nerd Fonts.
- ~subtree-state~: Shows ~v~ / ~>~ expand collapse indicators for subtrees.
- ~vc-state~: Adds version control status icons/indicators.
- ~file-size~: Human-readable file size column.

** Modeline & Header-Line Height Synchronization

Doom ensures Dirvish mode-line and header-line match the height of ~doom-modeline~:

#+begin_src elisp
(when (modulep! :ui modeline)
  (add-hook! 'dired-mode-hook
    (defun +dired-update-mode-line-height-h ()
      (when-let* ((height (bound-and-true-p doom-modeline-height)))
        (setq dirvish-mode-line-height height
              dirvish-header-line-height height)))))
#+end_src

*Why this matters:* Mismatched height between Dirvish header/mode-lines and standard mode-lines causes buffer jumpiness when switching windows.

** Dirvish Multi-Frame Redisplay Debouncing

Doom contains a critical bugfix for Dirvish when operating across multiple Emacs frames:

#+begin_src elisp
;; HACK: Guard dirvish-pre-redisplay-h so it only fires for the selected window in its frame
;; Prevents feedback loops where frame A's redisplay triggers frame B's redisplay causing visible flickering.
(defadvice! +dired--debounce-dirvish-redisplay-a (fn window)
  :around #'dirvish-pre-redisplay-h
  (when (eq (frame-selected-window) window)
    (funcall fn window)))
#+end_src

** Org-Modern Integration & Checkbox Fix

When the ~+pretty~ flag is active, Doom loads ~org-modern~ in =lang/org/contrib/pretty.el=:

#+begin_src elisp
(use-package! org-modern
  :hook (org-mode . org-modern-mode)
  :hook (org-agenda-finalize . org-modern-agenda)
  :init
  (after! org
    (setq org-hide-emphasis-markers t
          org-pretty-entities t))
  :config
  ;; Fix for oversized Unicode checked box: swap with consistent composition symbol
  (setf (alist-get ?X org-modern-checkbox) #("□x" 0 2 (composition ((2)))))

  ;; Automatically port org-todo-keyword-faces, org-tag-faces, org-priority-faces to inverse-video pills
  (letf! (defun new-spec (spec)
           (if (or (facep (cdr spec))
                   (not (keywordp (car-safe (cdr spec)))))
               `(:inherit ,(cdr spec))
             (cdr spec)))
    (unless org-modern-tag-faces
      (dolist (spec org-tag-faces)
        (add-to-list 'org-modern-tag-faces `(,(car spec) :inverse-video t ,@(new-spec spec)))))
    (unless org-modern-todo-faces
      (dolist (spec org-todo-keyword-faces)
        (add-to-list 'org-modern-todo-faces `(,(car spec) :inverse-video t ,@(new-spec spec)))))
    (unless org-modern-priority-faces
      (dolist (spec org-priority-faces)
        (add-to-list 'org-modern-priority-faces `(,(car spec) :inverse-video t ,@(new-spec spec)))))))
#+end_src

** Theme Integration (doom-themes-org-config)

* Actionable Recommendations for MyEmacs

To achieve Doom-grade aesthetics and reliability in ~MyEmacs~:

1. *In ~custom-files.el~ (Dirvish / Dired):*
   - Add TRAMP switch guard for GNU ~ls~ flags to prevent blank dired screens over remote SSH connections.
   - Set ~dirvish-attributes '(nerd-icons subtree-state file-size vc-state)~.
   - Ensure ~dirvish-mode-line-height~ and ~dirvish-header-line-height~ match custom mode-line height.
   - Set ~dirvish-reuse-session 'open~.

2. *In ~custom-org.el~ (Org Aesthetics):*
   - Add ~org-appear~ to automatically reveal emphasis markers (~*~, ~/~, ~=~, ~~~) when cursor is on them.
   - Add LaTeX preview scale: ~(plist-put org-format-latex-options :scale 1.5)~.
   - Apply Doom's checkbox composition fix for ~org-modern-checkbox~: ~#("□x" 0 2 (composition ((2))))~.
   - Ensure ~fixed-pitch~ face inheritance for Org tables, code blocks, and metadata tags so tables remain perfectly aligned.

3. *In ~custom-ui.el~ (Fonts & Themes):*
   - Maintain strict separation of ~doom-font~ (monospace) and ~doom-variable-pitch-font~ (proportional/prose).
   - Configure ~doom-themes-org-config~ or equivalent heading scale rules.
