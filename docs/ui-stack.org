* Overview

The Emacs UI stack transforms the default Emacs appearance into a modern,
visually coherent editing environment. These packages work together to provide:

- **Theming** — consistent color schemes with proper contrast ratios
- **Modeline** — minimal, informative status bar
- **Typography** — focused writing mode with centered text
- **Icons** — file-type and mode icons across the interface
- **Discoverability** — contextual keybinding hints
- **Polish** — cursor, scroll, and fringe refinements

#+begin_warning
This reference covers UI packages only. See =org-ecosystem.org= for Org mode
visual enhancements (org-modern), and =completion-stack.org= for completion
UI (vertico, orderless, marginalia, consult).
#+end_warning

* EF Themes (by Protesilaos)

** Purpose

EF Themes is a collection of 26 accessible color themes designed by
Protesilaos Stavrou. They prioritize proper contrast ratios (WCAG AAA
compliant), consistent color semantics, and support for a wide range of Emacs
faces and packages.

** Theme Categories

| Category  | Themes                                          |
|-----------+-------------------------------------------------|
| Dark      | ef-dark, ef-melissa-dark, ef-trio-dark          |
| Light     | ef-light, ef-melissa-light, ef-trio-light       |
| Seasonal  | ef-spring, ef-summer, ef-autumn, ef-winter      |
| Special   | ef-elea, ef-frost, ef-bio, ef-cyprus, etc.      |

** Configuration

#+begin_src elisp
(use-package ef-themes
  :config
  (setq ef-themes-to-toggle '(ef-spring ef-winter))
  (load-theme 'ef-winter t))
#+end_src

** Key Variables

| Variable                  | Default        | Purpose                              |
|---------------------------+----------------+--------------------------------------|
| =ef-themes-to-toggle=     | =nil=          | Pair of themes for =ef-themes-toggle= |
| =ef-themes-mixed-fonts=   | =nil=          | Allow mixed font styles              |
| =ef-themes-disable-faces= | =nil=          | Faces to disable from theming        |
| =ef-themes-headings=      | ='(1 . t)=     | Heading style (bold/weight)          |

** Theme Toggle

#+begin_src elisp
;; Toggle between two themes
(setq ef-themes-to-toggle '(ef-spring ef-winter))

;; Then use:
M-x ef-themes-toggle RET
#+end_src

The toggle switches between the two themes in the pair. This is useful for
quick light/dark switching.

** Loading Themes

#+begin_src elisp
;; Load a single theme (disables all others)
(load-theme 'ef-winter t)

;; The second argument `t` is critical — it disables previously loaded themes
;; Without it, multiple themes layer on top of each other
#+end_src

#+begin_warning
The =t= second argument to =load-theme= is critical. Without it, previously
loaded themes remain active, causing color conflicts and unpredictable
rendering. Always use =(load-theme 'ef-winter t)= to ensure a clean state.
#+end_warning

* Mood Line

** Purpose

Mood Line provides a minimal, single-line modeline that displays essential
information without clutter. It integrates with ef-themes and other UI

** Configuration

* Olivetti

** Purpose

Olivetti provides distraction-free writing mode by centering text and
controlling the width of the editable area. Ideal for prose, documentation,
and long-form writing.

** Configuration

#+begin_src elisp
(use-package olivetti
  :config
  (setq olivetti-body-width 0.8)
  (global-set-key (kbd "C-c z") #'olivetti-mode))
#+end_src

** Key Variables

| Variable                | Default | Purpose                              |
|-------------------------+---------+--------------------------------------|
| =olivetti-body-width=   | =85=    | Width of text area (characters)      |
| =olivetti-style=        | =fancy= | Style preset (fancy, plain)          |
| =olivetti-body-width=   | =0.8=   | When a float: 80% of window width    |
| =olivetti-margin-width= | =nil=   | Fixed margin width in characters     |

** Body Width Modes

| Value Type | Example | Behavior                              |
|------------+---------+---------------------------------------|
| Integer    | =80=    | Fixed width of 80 characters          |
| Float      | =0.8=   | 80% of window width (responsive)      |
| Function   | =func=  | Custom width calculator               |

** Recommended: Float Value

Using a float (e.g., =0.8=) is recommended because it:
- Adapts to window resizing
- Maintains readable proportions at any window size
- Works well with tiling window managers

#+begin_warning
=olivetti-body-width= of =0.8= means 80% of the window width, not 80
characters. At a 200-column window, this gives 160 columns of text area.
For a fixed character width, use an integer instead.
#+end_warning

** Auto-Enable for Specific Modes

#+begin_src elisp
;; Auto-enable olivetti for writing modes (via custom-writing.el)
(add-hook 'org-mode-hook #'olivetti-mode)
(add-hook 'markdown-mode-hook #'olivetti-mode)
(add-hook 'text-mode-hook #'olivetti-mode)

;; variable-pitch for body text, fixed-pitch for code/tables
;; See custom-writing.el for +carlos/writing-setup-variable-pitch
#+end_src

* Nerd Icons

** Purpose

Nerd Icons provides icon fonts for file types, modes, and UI elements. It
powers icons in =dirvish=, =dired=, =tab-bar=, and other packages that
display file-type indicators.

** Configuration

#+begin_src elisp
(use-package nerd-icons
  :config
  ;; Auto-install fonts if not present
  (unless (file-directory-p (expand-file-name "nerd-icons/fonts" user-emacs-directory))
    (nerd-icons-install-fonts t)))
#+end_src

** Font Installation

The Nerd Fonts must be installed on the system for icons to render:

#+begin_src elisp
;; Install fonts from within Emacs
M-x nerd-icons-install-fonts RET

;; Or install system-wide (macOS):
;; brew tap homebrew/cask-fonts
;; brew install --cask font-hack-nerd-font
#+end_src

** Available Icon Families

| Family              | Prefix             | Purpose                    |
|---------------------+--------------------+----------------------------|
| Devicon             | =devicon-=         | Programming language icons |
| Octicon             | =octicon-=         | GitHub-style icons         |
| File Icon           | =nerd-icons-file-= | File type icons            |
| File Type           | =nerd-icons-faicon=| FontAwesome icons          |
| Weather             | =nerd-icons-wicon= | Weather icons              |
| Material Design     | =nerd-icons-mdicon=| Material design icons      |
| Powerline           | =nerd-icons-pl=    | Powerline symbols          |

** Icon Usage

#+begin_src elisp
;; Get an icon for a file extension
(nerd-icons-icon-for-file "example.py")
;; → returns icon propertized string

;; Get an icon for a mode
(nerd-icons-icon-for-mode 'python-mode)
;; → returns icon propertized string

;; Custom icon
(nerd-icons-octicon "oct-mark-github")
#+end_src

** Font Verification

#+begin_src elisp
;; Check if nerd-icons fonts are installed
(nerd-icons-install-fonts t)
;; This installs to ~/.emacs.d/nerd-icons/fonts/
;; AND copies to system font directory
#+end_src

#+begin_warning
Installing fonts via =nerd-icons-install-fonts= copies them to the system
font directory, which may require sudo on Linux. On macOS, it copies to
=~/Library/Fonts/= which doesn't require elevated permissions. After
installing, you must restart Emacs for the fonts to be recognized.
#+end_warning

* Which Key

** Purpose

Which Key displays available keybindings in a popup after a short delay,
making Emacs's extensive keybinding system discoverable.

** Configuration

#+begin_src elisp
(use-package which-key
  :config
  (setq which-key-idle-delay 0.8)
  (setq which-key-show-early-on-C-h t)
  (which-key-mode 1))
#+end_src

** Key Variables

| Variable                       | Default | Recommended | Purpose                          |
|--------------------------------+---------+-------------+----------------------------------|
| =which-key-idle-delay=         | =1.0=   | =0.8=       | Seconds before popup appears     |
| =which-key-show-early-on-C-h=  | =nil=   | =t=         | Show on C-h prefix               |
| =which-key-side-window-location=| =bottom=| =bottom=    | Popup display position           |
| =which-key-max-display-columns=| =4=     | =4=         | Max columns in popup             |
| =which-key-separator=          | =" → "= | =" → "=     | Key-description separator        |

** Popup Behavior

- **Idle delay:** 0.8 seconds — fast enough to be useful, slow enough to
  not interrupt typing flow
- **C-h prefix:** Pressing =C-h= after a prefix key immediately shows
  available bindings without waiting for idle delay
- **Side window:** Appears at the bottom of the frame by default

** Customization

#+begin_src elisp
;; Replace specific key descriptions
(which-key-add-replacement-args
 '(("C-c" . "contextual")
   ("C-x" . "extended")
   ("M-x" . "execute")))

;; Hide specific keys
(which-key-add-key-based-replacements
 '("C-c p" "projectile"))
#+end_src

** Disabling for Specific Prefixes

#+begin_src elisp
;; Don't show which-key for these prefixes
(setq which-key-allow-evil-operators nil)
(add-to-list 'which-key-unsupported-modes 'vterm-mode)
#+end_src

* Visual Tweaks

** Purpose

Built-in Emacs variables that refine the editing experience without
requiring additional packages.

** Configuration

#+begin_src elisp
;; Parenthesis matching
(show-paren-mode 1)
(setq show-paren-style 'expression)

;; Scroll behavior
(setq scroll-conservatively 101)
(setq scroll-margin 3)

;; Fringe width
(fringe-mode '(8 . 8))
#+end_src

** Show Paren Mode

| Variable             | Value          | Behavior                           |
|----------------------+----------------+------------------------------------|
| =show-paren-mode=    | =1=            | Enable parenthesis matching        |
| =show-paren-style=   | =expression=   | Highlight entire matching expr     |

Style options:
- =parenthesis= — highlight only the matching parenthesis
- =expression= — highlight the entire expression between parens (recommended)
- =mixed= — parenthesis when near, expression when far

** Scroll Behavior

| Variable                  | Value | Behavior                               |
|---------------------------+-------+----------------------------------------|
| =scroll-conservatively=   | =101= | Never recenter; scroll by 1 line past  |
| =scroll-margin=           | =3=   | Keep 3 lines visible at top/bottom     |

#+begin_note
=scroll-conservatively= of 101 means: when cursor moves past the scroll
margin, scroll by one line instead of recentering the buffer. Any value >100
disables recentering entirely. This provides a smoother, more predictable
scrolling experience.
#+end_note

** Fringe Mode

| Call                 | Left | Right | Purpose                      |
|----------------------+------++-------+------------------------------|
| =(fringe-mode 8)=    | 8    | 8     | Symmetric fringes             |
| =(fringe-mode '(8 . 8))= | 8 | 8   | Explicit left and right       |
| =(fringe-mode '(0 . 8))= | 0 | 8   | Left hidden, right visible    |
| =(fringe-mode 0)=    | 0    | 0     | No fringes                    |

The fringe displays:
- Line continuation indicators
- Overlay icons (git status, breakpoints)
- Truncation arrows
- Scroll bar (when not using external scroll bar)

* Pitfalls & Common Errors

** P1: load-theme Second Argument

- **Symptom:** Colors look wrong, faces from multiple themes overlap
- **Cause:** =(load-theme 'ef-winter)= without =t= keeps previous themes active
- **Fix:** Always use =(load-theme 'ef-winter t)=
- **Severity:** High — visual corruption, hard to diagnose

** P2: ef-themes Contrast Issues

- **Symptom:** Some faces are unreadable or low contrast
- **Cause:** ef-themes are designed for specific contrast levels; mixing
  with non-ef themes breaks contrast guarantees
- **Fix:** Use only ef-themes; toggle between light/dark variants
  (e.g., =ef-spring= / =ef-winter=)
- **Severity:** Medium — accessibility impact

** P3: Nerd Icons Fonts Not Installed

- **Symptom:** Icons display as boxes or =?= characters
- **Cause:** Nerd Font not installed on the system or Emacs hasn't
  restarted since installation
- **Fix:** Run =M-x nerd-icons-install-fonts=, then restart Emacs
- **Severity:** Medium — cosmetic, affects all icon-dependent packages

** P4: olivetti-body-width Confusion

- **Symptom:** Text area is unexpectedly wide or narrow
- **Cause:** Float value (=0.8=) means percentage of window width, not
  character count
- **Fix:** Use integer (=80=) for fixed character width, float (=0.8=)
  for responsive percentage
- **Severity:** Low — cosmetic, easy to fix

** P5: which-key Too Aggressive

- **Symptom:** Popup appears during normal typing
- **Cause:** =which-key-idle-delay= too low
- **Fix:** Increase to =0.8= or =1.0= seconds
- **Severity:** Low — annoying but harmless

** P6: show-paren-mode Style Mismatch

- **Symptom:** Parenthesis highlighting doesn't match expectations
- **Cause:** =show-paren-style= defaults to =parenthesis=
- **Fix:** Set to =expression= for full expression highlighting
- **Severity:** Low — personal preference

* RAG Context Notes

** For LLM Context Injection**

When using this reference with AI assistants, include the following context points:

- =load-theme= with =t= as second argument disables all previous themes
- =olivetti-body-width= =0.8= means 80% of window width, not 80 characters
- nerd-icons fonts must be installed on the system OR via =nerd-icons-install-fonts=
- =ef-themes-to-toggle= sets up =M-x ef-themes-toggle= for light/dark switching
- =which-key-idle-delay= of 0.8 seconds is the recommended sweet spot
- =scroll-conservatively= > 100 disables buffer recentering entirely
- =show-paren-style= =expression= highlights the full s-expression, not just the paren
- =fringe-mode= takes an integer (both sides) or a cons ='(left . right)=

** Package Independence**

All UI packages are largely independent and can be mixed and matched:

- ef-themes works with or without mood-line
- olivetti works with any theme
- nerd-icons is a library used by other packages (dirvish, tab-bar)
- which-key works with any configuration
- Visual tweaks are always available
