Dirvish is a modern file manager that enhances Emacs' built-in =dired= mode with
a visual interface, sidebar, subtree navigation, file previews, version-control
integration, and more. It is the primary file-management tool in this Emacs
configuration (Vanilla Emacs migration from Doom Emacs, using the Bedrock
template).

* Installation
:PROPERTIES:
:RAG_IMPORTANT: t
:END:

Install Dirvish from MELPA or NonGNU ELPA:

#+begin_src emacs-lisp
M-x package-install RET dirvish RET
#+end_src

Or via =use-package= (preferred in this project):

#+begin_src emacs-lisp
(use-package dirvish
  :ensure t
  :init
  (dirvish-override-dired-mode 1))
#+end_src

#+begin_note
Dirvish depends on =dired= (built-in), =transient= (built-in since Emacs 28.1),
and optionally =nerd-icons=, =all-the-icons=, or =vscode-icon= for icon support.
Ensure =nerd-icons= is loaded before dirvish config that references it.
#+end_note

* Activation
:PROPERTIES:
:RAG_CRITICAL: t
:END:

Dirvish must be activated globally to override built-in Dired:

#+begin_src emacs-lisp
(dirvish-override-dired-mode 1)
#+end_src

#+begin_warning
ALWAYS place =(dirvish-override-dired-mode 1)= in the =:init= block of =use-package=,
NOT in =:config=. The =:init= block runs before the package is loaded, which is
necessary for the override to take effect on all Dired buffers.

WRONG:
#+begin_src emacs-lisp
(use-package dirvish
  :config
  (dirvish-override-dired-mode 1))  ;; Too late!
#+end_src

CORRECT:
#+begin_src emacs-lisp
(use-package dirvish
  :init
  (dirvish-override-dired-mode 1))  ;; Runs before package load
#+end_src
#+end_warning

* Core Concepts
:PROPERTIES:
:RAG_SECTION: t
:END:

Dirvish does not replace Dired --- it enhances it. Key concepts:

1. **Override mode** :: =dirvish-override-dired-mode= replaces all standard Dired
   entry points (=dired=, =dired-jump=, =find-dired=, etc.) with Dirvish equivalents.
2. **Root buffers** :: The main Dirvish buffer that displays directory listings.
   Each root buffer manages its own set of pane windows.
3. **Side window** :: A dedicated sidebar that mirrors the current directory tree.
   Toggled with =dirvish-side=.
4. **Subtree navigation** :: Expand/collapse subdirectories inline within the Dired
   buffer, creating a tree-view experience.
5. **Preview window** :: Show file contents (images, PDFs, text, etc.) in a
   dedicated preview pane.
6. **Attributes** :: Inline visual indicators (icons, git state, file size, etc.)
   rendered within Dired listing lines.
7. **Extensions** :: Optional modules loaded on demand (yank, rsync, emerge, peek,
   vc, icons, side, ls, subtree, history, quick-access, collapse, narrow).

** Quick Access Entries
:PROPERTIES:
:RAG_QUICKACCESS: t
:END:

Quick access entries provide two-keystroke jumps to frequently used directories:

#+begin_src emacs-lisp
(setq dirvish-quick-access-entries
      '(("h" "~/"                  "Home")
        ("d" "~/Downloads/"        "Downloads")
        ("p" "~/Projects/"         "Projects")
        ("e" "~/.config/emacs/"    "Emacs")
        ("n" "~/org/notes"         "Notes")
        ("g" "~/Github/"           "Github")))
#+end_src

Format: =("key" "path" "description")=
- =key= :: Single character used after invoking =dirvish-quick-access=
- =path= :: Directory path (expanded at runtime)
- =description= :: Label shown in the transient menu

:PROPERTIES:
:RAG_LAYOUT: t
:END:

| Variable                       | Type     | Default | Description                                       |
|--------------------------------+----------+---------+---------------------------------------------------|
| =dirvish-side-width=             | integer  | 30      | Width of the side window in columns               |
| =dirvish-fullscreen=             | boolean  | =t=       | Whether Dirvish occupies the entire frame          |
| =dirvish-default-layout=         | integer  | 0       | Layout index (typically 0-5, NOT 10)               |
| =dirvish-hide-cursor=            | boolean  | =t=       | Hide cursor in Dired buffers                       |

#+begin_warning
=dirvish-window-size= is NOT a standard Dirvish variable. To configure window
ratios, use =dirvish-layout-recipes= instead:

#+begin_src emacs-lisp
(setq dirvish-layout-recipes
      '((0 1 1)          ; Layout 0: single pane (full)
        (1 2 1)          ; Layout 1: two panes, ratio 2:1
        (2 1 1 1)))      ; Layout 2: three panes, ratio 1:1:1
#+end_src
#+end_warning

** Icon Settings
:PROPERTIES:
:RAG_ICONS: t
:END:

| Variable                          | Type    | Recommended | Description                                  |
|-----------------------------------+---------+-------------+----------------------------------------------|
| =dirvish-nerd-icons-height=         | integer | 16-18       | Icon height in pixels                        |
| =dirvish-nerd-icons-offset=         | integer | -2          | Vertical offset adjustment                   |
| =dirvish-subtree-icon-scale-factor= | float   | 1.0         | Scale factor for subtree expansion icons     |

#+begin_danger
RAG TRAP: =dirvish-nerd-icons-height= of 12 makes icons TOO SMALL, not too large.
The value represents the icon height in pixels. If you see giant icons, the value
is likely set too HIGH (e.g., 40+), not too low. Recommended range: 16-18 for
standard font sizes (14-16pt). Adjust based on your =default= face height.
#+end_danger

#+begin_src emacs-lisp
(setq dirvish-nerd-icons-height 16    ; Standard size for 14-16pt fonts
      dirvish-nerd-icons-offset -2)   ; Slight vertical adjustment
#+end_src

#+begin_note
=nerd-icons= must be loaded and fonts installed before Dirvish can render icons.
Ensure =(require 'nerd-icons)= or =(use-package nerd-icons)= appears before
Dirvish configuration, or use =:after nerd-icons= in the =use-package= declaration.
#+end_note

** Performance
:PROPERTIES:
:RAG_PERF: t
:END:

#+begin_src emacs-lisp
(setq dirvish-large-directory-threshold 20000)
#+end_src

Directories with more files than this threshold are opened asynchronously
using =fd= (requires =fd= CLI tool installed). This prevents Emacs from
freezing when opening directories with tens of thousands of files.

* Extensions
:PROPERTIES:
:RAG_EXTENSIONS: t
:END:

Dirvish ships optional extension packages under =/extensions/=, installed together
with the main package (MELPA). They are inactive by default and loaded on demand;
usually you do not need to =require= them explicitly. Extensions can add
commands/attributes/preview methods, improve the UI via =transient.el=, or
integrate external tools.

| Extension            | Feature                                             | Activation                        |
|----------------------+-----------------------------------------------------+-----------------------------------|
| =dirvish-yank=         | Multi-stage async copy/paste/move/symlink/hardlink   | Yank/move commands                |
| =dirvish-rsync=        | =rsync= file transfer + transient switches menu      | =dirvish-rsync= command             |
| =dirvish-emerge=       | Group files with a filter stack (ibuffer-like)       | =dirvish-emerge-mode= in setup     |
| =dirvish-peek=         | Minibuffer file preview (=vertico=, =ivy=, =icomplete=) | =dirvish-peek-mode= minor mode |
| =dirvish-vc=           | VC attributes + preview dispatchers                  | Automatic when =vc-state=/=git-msg= in attrs |
| =dirvish-icons=        | File icons (=nerd-icons=, =all-the-icons=, =vscode-icon=) | Automatic when icon in attrs |
| =dirvish-side=         | Sidebar window (file tree)                           | =dirvish-side= command              |
| =dirvish-ls=           | Change ls switches on the fly                        | =dirvish-quicksort= / =dirvish-ls-switches-menu= |
| =dirvish-subtree=      | Tree browser (expand/collapse subtrees)              | =dirvish-subtree-toggle=            |
| =dirvish-history=      | History navigation                                   | =dirvish-history-jump=              |
| =dirvish-quick-access= | Quick keys (2-keystroke jumps)                       | =dirvish-quick-access=              |
| =dirvish-collapse=     | Collapse unique nested paths                         | Automatic when =collapse= in attrs |
| =dirvish-narrow=       | Live filtering of directory contents                 | =dirvish-narrow= command            |

** Multi-stage copy/paste (=dirvish-yank.el=)

Implements the "two-stage" clipboard workflow: mark files in one or more Dired
buffers, go to the destination, then run one of:

- =dirvish-yank= / =dirvish-move= / =dirvish-symlink= / =dirvish-relative-symlink= / =dirvish-hardlink=

All operations run *asynchronously* without extra setup.

** =rsync= integration (=dirvish-rsync.el=)

=dirvish-rsync= mirrors =dired-rsync= but: handles same-remote-host operations,
uses the multi-stage action mechanism of =dirvish-yank= (mark files first, then
invoke from the target directory), and gathers marked files from multiple Dired
buffers.

User options:

- =dirvish-rsync-program= / =dirvish-rsync-args= — executable and CLI args.
- =dirvish-rsync-r2r-ssh-port=, =dirvish-rsync-r2r-ssh-user=, =dirvish-rsync-r2r-use-direct-connection= — remote-to-remote connections.
- =dirvish-rsync-shortcut-key-for-yank-menu=, =dirvish-rsync-use-yank-menu= — shortcut in =dirvish-yank-menu=.
- =dirvish-rsync-switches-menu= — transient menu for temporary arg tweaks.

** Group files with a filter stack (=dirvish-emerge.el=)

Organizes the file list into groups (presented like =ibuffer=); collapse/expand
groups with =TAB= on the group header.

- =dirvish-emerge-groups= — filter criteria (predicates and extensions).
- =dirvish-emerge-menu= — transient menu to build/compose/save groups (prefer it over editing the variable; save to =.dir-locals.el= for per-directory grouping).
- =dirvish-emerge-mode= — add to =dirvish-setup-hook= to group on entering a directory.

#+begin_src emacs-lisp
(add-hook 'dirvish-setup-hook 'dirvish-emerge-mode)
#+end_src

** Minibuffer file preview (=dirvish-peek.el=)

=dirvish-peek-mode= is a minor mode for minibuffer previews as you narrow
candidates. Supports =vertico=, =ivy= and =icomplete=.

- =dirvish-peek-key= — controls when previews trigger (like =consult-preview-key=):
  - ='any= — immediate on any key press (default)
  - =(list :debounce 0.5 'any)= — automatic with debounce
  - ="M-."= — manual, immediate
  - =(list :debounce 0.5 "M-."= — manual with debounce
  - =nil= — disabled

** Version-control (=git=) integration (=dirvish-vc.el=)

- =vc-state= — attribute showing VC state as a bitmap in the left fringe.
- =git-msg= — attribute showing the latest git commit message after the file name.
- =vc-log= / =vc-diff= / =vc-blame= — preview dispatchers. Put them at the *beginning*
  of =dirvish-preview-dispatchers= to use by default. They are mutually exclusive
  (e.g. =(vc-log vc-diff ...)= silently ignores =vc-diff=).
- =dirvish-vc-menu= (default binding =? v=) — calls VC commands and cycles the =vc-*= preview methods.

** File icons (=dirvish-icons.el=)

Backends: =nerd-icons=, =all-the-icons=, =vscode-icon=.

Options (appearance tweaks):

- =dirvish-all-the-icons-height=, =dirvish-all-the-icons-offset=, =dirvish-all-the-icons-palette=
- =dirvish-vscode-icon-size=
- =dirvish-nerd-icons-height=, =dirvish-nerd-icons-offset= — nerd-icons sizing / vertical offset (=:v-adjust= float).

** Sidebar (file tree) (=dirvish-side.el=)

=dirvish-side= toggles a Dirvish sidebar in the current frame. Resize with
=dirvish-side-increase-width= / =dirvish-side-decrease-width=. With
=dirvish-side-follow-mode= the side session selects the current buffer's file and
visits =project-root= after switching projects.

Options:

- =dirvish-side-attributes=, =dirvish-side-mode-line-format=, =dirvish-side-header-line-format=
- =dirvish-side-display-alist=, =dirvish-side-window-parameters=
- =dirvish-side-width=, =dirvish-side-open-file-action=, =dirvish-side-auto-expand=

** Setup ls switches on the fly (=dirvish-ls.el=)

- =dirvish-quicksort= — change sort criteria quickly.
- =dirvish-ls-switches-menu= — transient menu to edit listing switches.

** Tree browser (=dirvish-subtree.el=)

=dirvish-subtree-toggle= expands/collapses the directory under the cursor
(alternative to =dired-subtree=).

- Add =subtree-state= to =dirvish-attributes= to show expansion state.
- =dirvish-subtree-state-style= (=plus=, =arrow=, =chevron=, =nerd=) and
  =dirvish-subtree-icon-scale-factor= (cons ='(HEIGHT . V-ADJUST)=) adjust the indicator.
- =dirvish-subtree-always-show-state= =nil= hides indicators when nothing is expanded.

** History navigation (=dirvish-history.el=)

Commands:

- =dirvish-history-jump= — go to recently visited directories.
- =dirvish-history-go-forward= / =dirvish-history-go-backward= — session-local forward/back.
- =dirvish-history-last= — most recently used Dirvish buffer.

Options:

- =dirvish-history-sort-function= — sorting for =dirvish-history-jump=.

** Quick keys for frequently visited places (=dirvish-quick-access.el=)

Jump anywhere with minimal keystrokes (usually 2). Define entries in
=dirvish-quick-access-entries= and call =dirvish-quick-access=.

** Collapse unique nested paths (=dirvish-collapse.el=)

Provides the =collapse= attribute: a chain of directories containing a single
unique file/directory is presented as one entry, avoiding needless drilling (as
in =dired-collapse=).

** Live-narrowing of Dirvish buffer (=dirvish-narrow.el=)

=dirvish-narrow= live-filters the buffer as you type. =RET= finalizes; =C-g=
cancels; =revert-buffer= (=g=) restores the full view.

- With =orderless= installed, it is used to build =completion-regexp-list=; otherwise =split-string= is used.
- In =dirvish-fd= buffers, a leading =#= enables two-stage filtering: the part after =#= is passed to =fd= as a pattern and the remainder is applied as a secondary Dirvish filter (e.g. =#foo,bar baz= → =fd --and=foo --and=bar=, then filter =baz=).

To explicitly load an extension (rarely needed):

#+begin_src emacs-lisp
(require 'dirvish-yank)
(require 'dirvish-rsync)
(require 'dirvish-peek)
#+end_src

* Recommended Configuration
:PROPERTIES:
:RAG_CRITICAL: t
:RAG_CONFIG: t
:END:

This is the recommended Dirvish configuration for this project (Vanilla Emacs,
Doom migration, Bedrock template). Copy this block as-is and adjust paths to
match your system.

#+begin_src emacs-lisp
;; ─────────────────────────────────────────────
;; Dired base configuration
;; ─────────────────────────────────────────────
(use-package dired
  :ensure nil  ;; Built-in
  :custom
  (dired-listing-switches
   "-l --almost-all --human-readable --group-directories-first --no-group")
  (dired-dwim-target t)
  (dired-kill-when-opening-new-dired-buffer t))

;; ─────────────────────────────────────────────
;; Dirvish --- modern Dired replacement
;; ─────────────────────────────────────────────
(use-package dirvish
  :ensure t
  :init
  ;; MUST be in :init, not :config
  (dirvish-override-dired-mode 1)
  :custom
  ;; Quick-access entries (2-keystroke jumps)
  (dirvish-quick-access-entries
   '(("h" "~/"                    "Home")
     ("d" "~/Downloads/"          "Downloads")
     ("p" "~/Projects/"           "Projects")
     ("e" "~/.config/emacs/"      "Emacs")
     ("n" "~/org/notes"           "Notes")))
  ;; Visual attributes (order matters)
  (dirvish-attributes
   '(vc-state subtree-state nerd-icons collapse git-msg file-time file-size))
  ;; Icon settings
  (dirvish-nerd-icons-height 16)     ; 16-18 for standard fonts
  (dirvish-nerd-icons-offset -2)
  ;; Window / layout
  (dirvish-side-width 30)
  (dirvish-large-directory-threshold 20000)
  (dirvish-hide-cursor t)
  (dirvish-use-mode-line nil)
  ;; Preview
  (dirvish-preview-dispatchers
   '(image gif video audio epub pdf archive))
  :bind
  (:map dirvish-mode-map
   (";"   . dired-up-directory)
   ("?"   . dirvish-dispatch)
   ("TAB" . dirvish-subtree-toggle)
   ("o"   . dirvish-quick-access)
   ("r"   . dirvish-history-jump)
   ("s"   . dirvish-quicksort)
   ("v"   . dirvish-vc-menu)
   ("N"   . dirvish-narrow))
  ;; Global key bindings
  :bind
  (("C-x C-j" . dirvish-dwim)
   ("C-x d"   . dirvish)))
#+end_src

#+begin_note
Key points:
1. =dired= is built-in, so use =:ensure nil=
2. =dirvish-override-dired-mode= MUST be in =:init=
3. All custom variables in =:custom= block (use =use-package=)
4. Consolidate all config into one =use-package= block
5. Do NOT use multiple =with-eval-after-load 'dirvish= blocks
#+end_note

* Troubleshooting and Pitfalls
:PROPERTIES:
:RAG_TRAPS: t
:RAG_CRITICAL: t
:END:

This section documents known pitfalls and traps when configuring Dirvish.
These are critical for AI agents modifying this configuration.

** TRAP 1: Icon height value is inverted
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Wrong assumption:** =dirvish-nerd-icons-height 12= makes icons "too large"
- **Reality:** The value is pixel height. 12 makes icons TOO SMALL. 40+ makes
  them too large. Recommended: 16-18 for fonts sized 14-16pt.
- **Fix:** Set =(setq dirvish-nerd-icons-height 16)=

** TRAP 2: Multiple =with-eval-after-load= blocks
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Problem:** Multiple =with-eval-after-load 'dirvish= blocks scattered across
  config files cause ordering issues and make maintenance difficult.
- **Fix:** Consolidate all Dirvish configuration into a single =use-package=
  declaration with =:custom=, =:config=, and =:bind= sections.

** TRAP 3: Invalid =dirvish-default-layout= value
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Problem:** =dirvish-default-layout= takes a layout index number (typically
  0-5), not arbitrary values like 10.
- **Fix:** Use values 0-5, or define custom layouts in =dirvish-layout-recipes=.

** TRAP 4: =dirvish-window-size= does not exist
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Problem:** =dirvish-window-size= is NOT a standard Dirvish variable.
  Setting it has no effect and may cause byte-compiler warnings.
- **Fix:** Use =dirvish-layout-recipes= to define window size ratios:
  #+begin_src emacs-lisp
  (setq dirvish-layout-recipes
        '((0 1 1)    ; Layout 0: full width
          (1 2 1)    ; Layout 1: 2:1 ratio
          (2 1 1 1))) ; Layout 2: 1:1:1 ratio
  #+end_src

** TRAP 5: Override mode in wrong =use-package= block
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Problem:** Placing =(dirvish-override-dired-mode 1)= in =:config= instead of
  =:init= means Dired buffers created before Dirvish loads won't be overridden.
- **Fix:** Always use =:init (dirvish-override-dired-mode 1)=

** TRAP 6: Icon backend load order
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Problem:** =nerd-icons= (or other icon backend) must be loaded before Dirvish
  tries to render icons. If =nerd-icons= is loaded after Dirvish, icons won't
  appear or will cause errors.
- **Fix:** Ensure =nerd-icons= package is configured before =dirvish=, or add
  =:after nerd-icons= to the dirvish =use-package= declaration:
  #+begin_src emacs-lisp
  (use-package dirvish
    :after nerd-icons
    ...)
  #+end_src

** TRAP 7: TRAMP async process support
:PROPERTIES:
:RAG_TRAP: t
:END:

- **Problem:** Dirvish requires =tramp-direct-async-process= connection-local
  profile for full TRAMP (remote file) functionality. Without it, remote
  directory operations may be slow or fail.
- **Fix:** Add connection-local profile:
  #+begin_src emacs-lisp
  (add-hook 'tramp-connection-properties
            '(("direct-async-process" . t)))
  #+end_src

* TRAMP Support
:PROPERTIES:
:RAG_TRAMP: t
:END:

Dirvish supports remote file access via TRAMP. For optimal performance:

1. Install =fd= on remote machines for async directory listing
2. Enable direct async process support:

#+begin_src emacs-lisp
;; TRAMP connection-local profile for async processes
(connection-local-set-profile-variables
 'dirvish-tramp-async
 '((tramp-direct-async-process . t)))

(connection-local-set-profile-enabler
 'dirvish-tramp-async
 (lambda ()
   (string-prefix-p "/ssh:" default-directory)))

(add-hook 'tramp-connection-properties
          '(("/ssh:" dirvish-tramp-async)))
#+end_src

#+begin_note
The =fd= (find-duplicate) CLI tool must be installed on remote machines for
async directory listing to work. Without it, Dirvish falls back to synchronous
=ls=, which can be slow for large remote directories.
#+end_note

* Migration from Doom Emacs
:PROPERTIES:
:RAG_MIGRATION: t
:END:

If migrating from Doom Emacs (which uses =+dirvish= module), note:

1. Doom sets =dirvish-override-dired-mode= automatically --- you must add it
   explicitly in Vanilla Emacs
2. Doom may use =all-the-icons= by default --- this project uses =nerd-icons=
3. Doom's Dirvish module configures many defaults --- review all =dirvish-*=
   variables in your Doom config and port the ones you want
4. Doom uses =general.el= for keybindings --- convert to standard =:bind= in
   =use-package=
5. Remove any =(require '+dirvish)= or doom-specific dirvish references

#+begin_src emacs-lisp
;; Doom Emacs dirvish config (REMOVE this)
;; (use-package! dirvish ...)

;; Vanilla Emacs equivalent (USE this)
(use-package dirvish
  :ensure t
  :init
  (dirvish-override-dired-mode 1)
  ;; ... rest of config
  )
#+end_src
