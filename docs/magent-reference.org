* Smart-Edit — Editor Transacional (=custom-magent-tool-smart-edit.el=)

Infraestrutura de edição segura para todas as ações de smart-edit (org + 8 linguagens code).
Cada mutação é executada como uma *transação*: snapshot do buffer antes, execução do thunk,
validação de integridade (org-lint ou check-parens), e restauração byte-a-byte em caso de falha.

** +carlos/magent--smart-edit-transaction (buf kind thunk)
- *Tipo:* Função
- *Módulo:* =lisp/custom-magent-tool-smart-edit.el= (linha 36)
- *Parâmetros:*
  - =buf= — buffer alvo (file-backed para persistência)
  - =kind= — =\\='org= (org-lint gate), =\\='code= (check-parens gate), ou =\\='raw= (sem gate de domínio)
  - =thunk= — função sem argumentos que executa as mutações e devolve a mensagem de sucesso
- *Comportamento:*
  1. Snapshot via =buffer-substring-no-properties=
  2. Executa thunk, captura valor de retorno (=msg=)
  3. Gate de validação conforme kind (org-lint para .org, check-parens para código)
  4. =basic-save-buffer= para persistir
  5. Em erro: restore byte-a-byte do snapshot, save, retorna string de erro (nunca sinaliza)
- *Exemplo:* =(+carlos/magent--smart-edit-transaction buf \\='code (lambda () (goto-char (point-max)) (insert " x") "inserido"))=

** +carlos/magent--smart-edit-replace-core (old new &optional flags)
- *Tipo:* Função
- *Módulo:* =lisp/custom-magent-tool-smart-edit.el= (linha 63)
- *Parâmetros:*
  - =old= — texto literal a buscar
  - =new= — substituto
  - =flags= — =nil= ou ="ALL"= (literal global), ="FIRST"= (primeira ocorrência), ="WORD"= (fronteiras de símbolo via =\\_<...\\_>=), ="REGEX"= (padrão regex bruto)
- *Retorno:* contagem de substituições (inteiro)
- *Nota:* =search-forward= já é literal por padrão; =WORD= e =REGEX= são as únicas formas que usam regexp.

** Regra de ouro: primitive-undo removido
Nenhuma variante usa mais =primitive-undo= (API de undo-list, não buffer — rollback
anterior era fictício). Todas as mutações passam pelo helper transacional que garante
rollback byte-a-byte via snapshot/restore. Meta-teste ERT
=myemacs-smart-edit-no-primitive-undo= valida que =primitive-undo= não reaparece.

* DevOps Tools (=custom-magent-tool-devops.el= / =custom-magent-tool-git.el=)

Ferramentas nativas para operações destrutivas em Docker, Systemd e Git.
Todas seguem o padrão *dry_run* para preview seguro antes da execução.

** Padrão dry_run (operação destrutiva)

Três tools destrutivas aceitam o parâmetro =dry_run= (string "true"):

| Tool                  | Ações destrutivas          | Fonte                              |
|-----------------------|----------------------------|-------------------------------------|
| =docker_action=       | =remove=, =rm=, =stop=     | =custom-magent-tool-devops.el=     |
| =systemd_action=      | =stop=, =disable=          | =custom-magent-tool-devops.el=     |
| =magit_branch_delete= | (todas as deleções)        | =custom-magent-tool-git.el=        |

*Comportamento:*

1. Se =dry_run= não é ="true"= → executa normalmente.
2. Se =dry_run= é ="true"= → retorna JSON com:
   - =status= = ="dry_run"=
   - =destructive= = =t= ou =nil= (se ação é destrutiva)
   - =command= → comando que seria executado
   - =message= → descrição legível

*Exemplo de resposta dry_run:*
#+begin_src json
{"status": "dry_run", "destructive": true, "command": "docker rm 'web'", "container": "web", "action": "remove", "message": "Would remove container 'web'."}
#+end_src

*Nota:* o parâmetro =dry_run= usa =string= (não =boolean=) porque o gptel serializa tudo como JSON string. A comparação interna é =(equal dry-run "true")=.

** docker_action (=+carlos/magent-tool-docker-action=)

Ações de lifecycle em containers Docker (local ou TRAMP).

- *Parâmetros:*
  - =container_id= -- nome ou ID do container
  - =action= -- =start=, =stop=, =restart=, =remove=
  - =remote_host= -- prefixo TRAMP opcional (ex: =/ssh:admin@host:=)
  - =dry_run= -- ="true"= para preview sem executar
  - =reason= -- justificativa (display-only)

** systemd_action (=+carlos/magent-tool-systemd-action=)

Gerenciamento de units systemd (local ou TRAMP).

- *Parâmetros:*
  - =unit= -- nome da unit (ex: =nginx.service=, =docker=)
  - =action= -- =start=, =stop=, =restart=, =reload=, =enable=, =disable=
  - =remote_host= -- prefixo TRAMP opcional
  - =dry_run= -- ="true"= para preview sem executar
  - =reason= -- justificativa (display-only)

** magit_branch_delete (=+carlos/magent-tool-magit-branch-delete=)

Exclui branches locais ou remotas via Magit API.

- *Parâmetros:*
  - =branch= -- nome da branch alvo
  - =remote= -- nome do remote (ex: =origin=) ou ="true"= para remota
  - =force= -- ="true"= para force delete (-D)
  - =dry_run= -- ="true"= para preview sem executar
  - =reason= -- justificativa (display-only)

*Nota:* esta tool requer =magit= carregado. Em batch sem magit, retorna erro informativo.
