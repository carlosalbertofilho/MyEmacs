* Introdução

Este guia cobre movimentação, atalhos e truques do Emacs Vanilla (MyEmacs).
Sem Evil mode — tudo usa atalhos nativos do Emacs com prefixo =C-c=.

* Conceitos Fundamentais

** Notação de Teclas

| Notação | Significado |
|---------+-------------|
| =C-x= | Ctrl + x |
| =M-x= | Alt (Option) + x, ou =Esc= depois =x= |
| =C-c C-e= | Ctrl+c, depois Ctrl+e |
| =s-h= | Super (Cmd) + h |
| =RET= | Enter |
| =DEL= | Backspace |

** Prefixos

- =C-x= : comandos de buffer/arquivo
- =C-c= : comandos customizados (meus bindings)
- =M-x= : executar qualquer comando pelo nome
- =s-= (Super/Cmd) : navegação de janelas

** Buffers e Janelas

- *Buffer*: conteúdo editado (arquivo, terminal, chat)
- *Janela*: divisão da tela que exibe um buffer
- *Frame*: janela do sistema operacional (pode ter várias janelas internas)

* Completamento

** Vertico (minibuffer)

- Aparece automaticamente ao digitar no minibuffer
- =C-n= / =C-p= : navegar candidatos
- =RET= : selecionar
- =M-RET= : selecionar sem fechar minibuffer

** Corfu (completamento inline)

- Aparece automaticamente enquanto digita código
- =TAB= : completar / próximo candidato
- =S-TAB= : candidato anterior
- =RET= : aceitar
- =C-g= : cancelar

** Consult

- =C-x b= : buscar buffers (fuzzy)
- =C-c s= : ripgrep no projeto
- =C-c S= : buscar linhas no buffer

** Embark

- =C-.= : agir no candidato sob o cursor (contextual)
- =C-;= : ação padrão no candidato

** Dica: encontrar qualquer comando

=M-x= e digitar parte do nome. O consult faz busca fuzzy.

** Dica: descobrir atalhos

=C-h k= seguido do atalho → mostra o comando vinculado.
=C-h f= seguido do nome → mostra documentação da função.

** Dica: qual comando está neste atalho?

=C-h k= e pressione o atalho. Mostra tudo.

** Dica: ajuda contextual

=C-h m= mostra todos os modos ativos e seus atalhos no buffer atual.

* Problemas Comuns

** vterm não funciona

Compilar o módulo: =M-x vterm-install= (requer GUI, cmake, gcc).

** pdf-tools não compila no macOS

Compilar manualmente:
#+begin_src shell
cd ~/.config/emacs-vanilla/elpa/pdf-tools-*/
./autogen.sh
./configure --bindir=$(pwd)/build/server
make
#+end_src

** Flycheck diz "no checker"

No buffer =*scratch*=, o checker emacs-lisp exige arquivo salvo.
Use =C-u C-c ! x= para habilitar manualmente, ou salve o arquivo.

** Pacotes não instalam

=M-x package-refresh-contents= e tente novamente.

** Emacs lento na primeira abertura

Normal — está baixando e compilando pacotes. Depois fica rápido.

* Configuração Nix

Para aplicar mudanças no Nix:
#+begin_src shell

* Dashboard (estilo Nano Emacs)

** Filosofia

Dashboard minimalista inspirado no =nano-emacs= de Nicolas Rougier:
- Sem logo gigante, texto centralizado e elegante
- Zero dependências extras (usa =recentf=, =project.el= nativos)
- Keyboard-first: navegação por atalhos, mouse opcional
- Integração direta com gptel, dirvish, magit

** Atalhos

| Atalho | Ação |
|--------+------|
| =C-c d d= | abrir dashboard |
| =C-c d r= | refresh dashboard |
| =q= / =C-g= | fechar dashboard |
| =f= | find file (consult-fzf) |
| =p= | switch project |
| =a= | org agenda |
| =g= | magit status |
| =i= | gptel chat |
| =d= | dirvish cwd |
| =TAB= / =S-TAB= | navegar entre seções |

** Widgets

- *Quick Actions*: links clicáveis para comandos frequentes
- *Recent Files*: últimos 8 arquivos (recentf)
- *Projects*: últimos 5 projetos (project.el)
- *Agenda*: itens de hoje (org-agenda)
- *Footer*: atalhos + uptime

** Splash Screen

Ao iniciar Emacs (sem arquivos abertos):
- Texto centralizado "MyEmacs" + versão + data
- Fade-out em 0.5s ou qualquer tecla
- Não aparece se abrir arquivo via linha de comando
