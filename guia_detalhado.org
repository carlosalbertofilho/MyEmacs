* Introdução

Este guia é projetado para levar você do zero à fluência no MyEmacs de forma
progressiva. Cada seção constrói sobre a anterior. Não tente aprender tudo de
uma vez — domine um nível antes de avançar.

** Filosofia

- **Keyboard-first:** Tudo tem atalho. Mouse é opcional.
- **C-c prefix:** Seus atalhos usam =C-c= seguido de letra.
- **Progressivo:** Comece simples, adicione complexidade quando confortável.
- **Consistente:** Mesmo padrão em todos os módulos.

* 42 School — Norminette e Estilo C

** Norminette (checker de estilo 42)

A integração com a Norminette foi reimplementada usando output JSON:

| Ação | Comando | Descrição |
|------+---------+-----------|
| Verificar buffer | =M-x custom-norminette-check-buffer= | Checa sem salvar arquivo |
| Toggle checker | =M-x custom-norminette-toggle= | Liga/desliga |
| Selecionar checker | =M-x custom-norminette-select-checker= | Ativa norminette |
| Auto-check on save | Automático | Roda ao salvar arquivo .c/.h |

** Chain de diagnóstico:**
#+begin_src text
eglot (clangd LSP) → norminette (style checker)
       ↓                      ↓
  syntax errors         norm violations
#+end_src

** Erros comuns com dicas:**
| Erro | Dica |
|------+------|
| INVALID_HEADER | Use =C-c h= para inserir/atualizar header |
| TOO_MANY_FUNCS | Máx 5 funções por arquivo — divida |
| TOO_MANY_LINES | Máx 25 linhas por função — refatore |
| SPACE_REPLACE_TAB | Use tabs para indentação |
| TOO_MANY_VARIABLES | Máx 5 variáveis por função |

** Estilo C 42 (automático em arquivos .c/.h):**
- Tabs reais (width 4)
- 80 colunas máx
- 25 linhas máx por função
- 5 variáveis máx por função
- Header 42 obrigatório (=C-c h=)
- Whitespace visível e cleanup no save
