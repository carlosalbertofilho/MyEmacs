** TODO Subagentes Sem Tools — Falha em Executar Trabalho Real
    :PROPERTIES:
    :CREATED: 2026-08-20
    :ASSIGNEE: opus
    :STATUS: plano aprovado
    :END:

*** Problema

Subagentes spawned pelo orquestrador não conseguem completar nenhuma tarefa
real. Três modos de falha observados:

1. *Timeout 120s* — modelos locais (qwen2.5-coder:3b) e free (gemini-3.5-flash)
   fazem timeout antes de concluir.
2. *"Subagent tools unavailable"* — modelo paid (gpt-5.6-sol via Zen) relata
   que =spawn_agent=/=wait_agent= não estão disponíveis (pois subagentes não delegam),
   tentando chamar =spawn_agent= devido a poluição de diretivas.
3. *"Could not parse HTTP response"* — falha de parsing na resposta HTTP
   do subagente paid quando tenta invocar ferramenta negada.

*** Evidência

Sessão =session-20260820-131932= (prompt Round 3: "analise
custom-magent-fsm.el e descreva os estados da máquina"):

| Tentativa | Modelo | Tier | Resultado |
|-----------|--------|------|-----------|
| 1 | qwen2.5-coder:3b | local | timeout 120s |
| 2 | gemini-3.5-flash | free | timeout 120s |
| 3 | gpt-5.6-sol | paid | "subagent tools unavailable" |
| 4 | gpt-5.6-sol | paid | "Could not parse HTTP response" |
| 5 | gpt-5.6-sol | paid | "Could not parse HTTP response" |

5 spawns, 0 successfully read file. Orquestrador desistiu.

*** Diagnóstico (Causa Raiz Confirmada pelo Opus)

1. *Poluição de Diretivas:* O advice =+carlos/magent-inject-system-directives= injetava
   a Diretiva #8 ("You are the ORCHESTRATOR... use spawn_agent") em TODOS os agentes.
   O subagente recebia essa instrução, tentava chamar =spawn_agent= (que é negado para subagentes),
   gerando os erros de "Subagent tools unavailable" e parse HTTP.
2. *Caminho Relativo no Prompt:* O Orquestrador passou o prompt relativo "analise custom-magent-fsm.el"
   sem expandir para o caminho absoluto completo (/home/carlosfilho/.../custom-magent-fsm.el).

*** Plano de Solução (3 Passos — Arquitetura de Diretivas)

1. *Tripla Divisão das Diretivas (=lisp/custom-magent-tools.el=):*
   - =+carlos/magent-common-directives=: Diretivas técnicas de execução nativa de ferramentas
     (Caminhos Absolutos, Parâmetros Não-Vazios, DSML Tool Call Format, SIGPIPE, Non-interactive shell).
   - =+carlos/magent-orchestrator-directives=: Diretivas estratégicas do Orquestrador
     (Delegação Estrita, Subagent Lifecycle, PADE Spawn-and-Forge, Model Selection, Subagent Retry, Síntese ≤3 tópicos).
   - =+carlos/magent-subagent-directives=: Diretivas específicas de Subagente Executor
     (Declaração de Papel Executor sem Delegação, Substituição Exata de Texto, Buffer Self-Healing, Proibido `spawn_agent`).

2. *Injeção Dinâmica por Papel via Advice `:around` (=lisp/custom-magent-tools.el= & =lisp/custom-magent-subagent.el=):*
   - Alterar =+carlos/magent-inject-system-directives= de `:filter-return` para `:around`
     \(=+carlos/magent-inject-system-directives-a=\), recebendo =agent-info=.
   - Determinar =is-orchestrator= inspecionando `(magent-agent-info-name agent-info)` e
     `+carlos/magent-subagent-profile`.
   - Se Orquestrador: injetar `common` + `orchestrator` + Menu de Modelos.
   - Se Subagente: injetar `common` + `subagent`.

3. *Reforço de Caminhos Absolutos & Testes ERT (=tests/magent-subagent-test.el=):*
   - Incluir a regra =ABSOLUTE PATHS IN PROMPTS (CRITICAL)= na suíte de diretivas do Orquestrador.
   - Criar os testes =myemacs-magent-orchestrator-prompt-content= e
     =myemacs-magent-subagent-prompt-content= para garantir regressão zero.

*Arquivos:* =lisp/custom-magent-tools.el=, =lisp/custom-magent-subagent.el=, =tests/magent-subagent-test.el=.
*Próximo:* Aplicar divisão de diretivas → refatorar advice para `:around` → validar suíte ERT via =just test-all=.
   são a única via viável (locais/free sempre dão timeout).
