* Plano Diretor — Ambição e Pipeline de Execução

** A Ambição (north star)

#+BEGIN_QUOTE
Magent/gptel como driver do Emacs: o agente opera o editor como um parceiro de
pareamento em vez de cuspir código para revisão. Em vez de escrever uma função
inteira, o modelo expande um tempel snippet e preenche apenas as lacunas —
usando o buffer vivo, flycheck/LSP para validar e corrigir em loop, e xref para
resolver símbolos reais (sem alucinar nomes).
#+END_QUOTE

Exemplo concreto (alvo): "adiciona um helper para X" → =lsp_navigation= resolve
o símbolo → =snippet_expand= insere o esqueleto em point → o modelo preenche só
os campos → =flycheck_errors= valida → corrige até zero erros. Nada de bloco
inteiro colado.

** Pipeline de execução (do chão até a ambição)

*** Etapa A — Fundação (chão estável; itens paralelos, baixo risco)

1. *Fluxo de dev Elisp* (DONE 2026-08-12) — gerador de testes ERT via IA

   runtime do jinx, opcional) — quick-wins de portabilidade/estabilidade; não

*** Etapa B — Motor (modelo + contexto sob controle; 3 antes de 4)

3. *Modelo com tool-calling confiável* (DONE 2026-08-12): benchmark executado e
   default configurado.
4. *Contexto sob controle (100% Automático)* (DONE 2026-08-12): opção 4 híbrida

*Contexto:* análise dos projetos RAG (Rank04) e Agent_Smith (Rank05) revelou

*** DONE [#A] Cooldown entre compactações
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-19
    :STATUS: concluido
    :END:
- *Problema:* =+carlos/magent-last-compaction-time= é gravado mas nunca lido.
  Se tokens crescem rápido pós-compactação, thrashing.
- *Abordagem:* defcustom =+carlos/magent-compaction-cooldown-seconds= (default
  120s); verificar no sink antes de chamar =+carlos/magent-compact=; log quando
  pular por cooldown.
- *Critério de saída:* =just compile= zero-warning; 2 testes ERT novos
  (cooldown ativo + cooldown expirado); =just test-all= verde.
- *Arquivos:* =lisp/custom-magent-context.el=, =tests/context-test.el=.

*** DONE [#A] Métricas por turno
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-20
    :STATUS: concluido
    :END:

  diagnosticar desperdício.
- *Abordagem:* alist =+carlos/magent-turn-metrics= (turn-id → input/output
  tokens + elapsed + tool-name); acumular no sink =turn-end=; novo comando

  =+carlos/magent-top-tokens-turns= retorna top-5.

- *Arquivos:* =lisp/custom-magent-context.el=, =tests/context-test.el=.

*** DONE [#B] Cap por tool result
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-20
    :STATUS: concluido
    :END:

  consome ~10K tokens de uma vez.
- *Abordagem:* defcustom =+carlos/magent-tool-result-max-chars= (default 8000);

  a =buffer_read= (estado vivo).
- *Critério de saída:* =just compile= zero-warning; 2 testes ERT novos
  (truncamento + preservação de buffer_read); =just test-all= verde.
- *Arquivos:* =lisp/custom-magent-tools.el=, =tests/magent-tools-test.el=.

*** DONE [#A] Orquestrador mais agressivo
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-19
    :STATUS: concluido
    :END:
- *Problema:* orquestrador faz 1 tool call por turno — consome tokens
  com contextos repetidos e turns curtos demais.
- *Abordagem:* reescrever regra 8 de =+carlos/magent-system-directives=
  para: (a) padrão "spawn-and-forge" — múltiplos =spawn_agent= antes de
  =wait_agent= quando tarefas independentes; (b) synthesis obrigatória
  em ≤3 bullets após =wait_agent= (nunca colar transcript).
- *Execução (2026-08-17):* commit 59400e0 (regra 8 reescrita + regra
  10 synthesis format); 2 testes ERT novos (spawn-and-forge, synthesis).
  Suíte: 312/305/0/7.

*** DONE [#B] Fallback de modelo inteligente
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-20
    :STATUS: concluido
    :END:
- *Problema:* watchdog dispara → FSM vai para =idle= → turno perdido.
  Subagente falha por timeout/modelo indisponível sem retry.
- *Abordagem:* novo sink =+carlos/magent-fsm-retry-on-failure= no
  =turn-end-sink=: se falha é "model_unavailable" ou "timeout",
  selecionar modelo de tier acima (local→free→paid) e retry automático
  (máx 1x por subagente, flag =:retried=). Se falha é
  "context_length_exceeded", compactar antes de retry.
- *Execução (2026-08-17):* commit 9df372b (classify-failure,
  record-failure, mark-retried, resume-up-tier, regra 11 directives);
  7 testes ERT novos. Suíte: 319/312/0/7.

*** DONE [#B] Compactação seletiva algorítmica
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-21
    :STATUS: concluido
    :END:
- *Problema:* compactação atual é "tudo ou nada" — quando threshold é
  atingido, compacta sessão inteira via
  =magent-runtime-session-compact=. Perde contexto útil junto com lixo.
- *Abordagem:* algoritmo puramente algorítmico (sem LLM) que analisa
  turns por peso e valor: (a) candidatos = turns com tool results >
  2000 tokens (read_file/grep pesados); (b) preservar: user prompts,
  syntheses do orquestrador, turns < 1000 tokens; (c) remover: tool
  results > 2000 tokens, transcripts completos de subagentes; (d)
  mecanismo =+carlos/magent-selective-compact-execute= usando
  =magent-thread-trim-turn= para remover turns individuais.
- *Execução (2026-08-17):* commit 6775acb (cumulative-tool-result-chars,
  selective-compact-p, build-selective-compaction-instruction,
  integração auto-compact); 5 testes ERT novos. Suíte: 324/317/0/7.

*** TODO D11. Pipeline de Documentação via Chat (Logic Extractor + Tech-Writer)
    :PROPERTIES:
    :CREATED: 2026-08-18
    :ASSIGNEE: planner
    :STATUS: backlog
    :TAGS: :magent:tools:
    :END:

*Contexto:* orquestrador deve reconhecer intenção do usuário ("explica o que X
faz", "documenta esse módulo", "analisa as regras de negócio") e acionar
pipeline de dois estágios automaticamente (sem keybinding).

*Pipeline:*
1. Orquestrador lê arquivo (=read_file=);
2. =spawn_agent('logic-extractor', código)= → extrai JSON com regras de negócio;
3. =wait_agent= → recebe JSON;
4. =spawn_agent('tech-writer', JSON + instrução Org)= → converte para =.org=;
5. =wait_agent= → recebe documentação;
6. Sintetiza ≤3 bullets para o usuário; oferece salvar =.org= se solicitado.

*Abordagem:*
- Novo perfil =logic-extractor= em =+carlos/magent-subagent-profiles=
  (:min-tier "free") — analista de código, não refatora, não testa,
  apenas traduz código imperativo → regras declarativas (JSON).
- Instrução dedicada =+carlos/magent-logic-extractor-instruction=:
  schema JSON com =modulo=, =proposito=, =pre_condicoes=, =regras=,
  =side_effects=.
- Instrução =+carlos/magent-tech-writer-instruction= ajustada para
  receber JSON e produzir =.org= válido (=* Modulo= → =** Propósito= →
  =** Regras= → =** Efeitos Colaterais=).
- Regra 12 em =+carlos/magent-system-directives=:
  "When user asks to 'document', 'explain what this does', or 'analyze
  business logic': spawn logic-extractor, wait, spawn tech-writer, wait,
