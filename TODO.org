* Plano Diretor — Ambição e Pipeline de Execução

** A Ambição (north star)

#+BEGIN_QUOTE
Magent/gptel como driver do Emacs: o agente opera o editor como um parceiro de
pareamento em vez de cuspir código para revisão. Em vez de escrever uma função
inteira, o modelo expande um tempel snippet e preenche apenas as lacunas —
usando o buffer vivo, flycheck/LSP para validar e corrigir em loop, e xref para
resolver símbolos reais (sem alucinar nomes).
#+END_QUOTE

Exemplo concreto (alvo): "adiciona um helper para X" → =lsp_navigation= resolve
o símbolo → =snippet_expand= insere o esqueleto em point → o modelo preenche só
os campos → =flycheck_errors= valida → corrige até zero erros. Nada de bloco
inteiro colado.

*** DONE [#C] Corrigir epdfinfo do Nix abortando no macOS (Abort trap: 6)
    :PROPERTIES:
    :ASSIGNEE: executor
    :DUE: 2026-08-20
    :STATUS: done
    :RESOLVED: 2026-08-16
    :END:
    - *Objetivo:* tornar pdf-tools utilizável no macOS com o epdfinfo do Nix.
    - *Causa-raiz (investigação 2026-08-16):* o binário do Nix aborta também no
      shell (não é problema de =fork()= do Emacs — diagnóstico anterior era falso
      positivo por testar sem =open:=/render). Stack: =poppler_page_render_full->
      std::mutex::lock()-> std::system_error (Invalid argument)->
      SIGABRT=. `PopplerPage::mutex` é zero-inicializado pelo GObject; no macOS um
      `std::mutex` zeroizado falha o lock com =EINVAL= (provado por teste isolado).
      No Linux zeros = initializer válido (por isso o CI do nixpkgs não pegou).
    - *Solução aplicada:* overlay darwin no MyMachine patcheando o poppler 26.06.0
      com o fix upstream (poppler Issue #1743, commit 08f4bca6, lançado no
      26.07.0) — construct/destruct do mutex em =poppler_page_init/finalize=;
      rebuild de poppler-glib + pdf-tools + epdfinfo. Commit f4f6ffc
      (MyMachine, fix-poppler-mutex-darwin). Remover o overlay quando o nixpkgs
      subir para poppler >= 26.07.0.
    - *Validação (2026-08-16):* protocolo open+renderpage no shell exit=0;
      =pdf-info-check-epdfinfo= OK no Emacs GUI; =pdf-info-renderpage= retornou
      PNG válido; PDF abre em =pdf-view-mode= (2 páginas).
    - *Prazo:* 2026-08-20.
