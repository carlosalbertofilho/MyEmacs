*** Problema

Subagentes spawned pelo orquestrador não conseguem completar nenhuma tarefa
real. Três modos de falha observados:

1. *Timeout 120s* — modelos locais (qwen2.5-coder:3b) e free (gemini-3.5-flash)

2. *"Subagent tools unavailable"* — modelo paid (gpt-5.6-sol via Zen) relata
   que =spawn_agent=/:wait_agent= não estão disponíveis (esperado, são
   orquestrador-only), mas também não consegue ler arquivos.
3. *"Could not parse HTTP response"* — falha de parsing na resposta HTTP
   do subagente paid.

*** Diagnóstico (3 hipóteses)

**** H1: =magent-enable-tools= não inclui tools padrão para subagentes

Código em =custom-magent-subagent.el:134-136=:
#+BEGIN_SRC elisp
(magent-enable-tools (if (and is-orchestrator (boundp 'magent-enable-tools))
                         (remq 'read (remq 'write (remq 'edit
                           (remq 'snippet_expand (remq 'buffer magent-enable-tools)))))
                       (when (boundp 'magent-enable-tools) magent-enable-tools)))
#+END_SRC

Para orquestrador: remove =read=, =write=, =edit=, =snippet_expand=, =buffer=.
Para subagente: retorna =magent-enable-tools= como está.

*magent-enable-tools= só contém* (de =custom-magent-tools.el:881-885= e
=custom-magent-buffer.el:481-482=):
- =flycheck_errors=, =lsp_navigation=, =snippet_expand=, =select_model=, =buffer=

*Não inclui:* =read_file=, =write_file=, =edit_file=, =bash=, =grep=, =glob=.

*Hipótese:* essas tools são upstream (magent core) e não passam por
=magent-enable-tools=. Se o upstream não as injeta para subagentes,
ficam indisponíveis.

**** H2: Tools upstream não são propagadas para sessões de subagente

O upstream (=magent-llm-gptel=) pode definir tools apenas para a sessão
do orquestrador. Subagentes recebem uma sessão isolada sem as tools
upstream (=read_file=, =bash=, etc.).

**** H3: Timeout é o problema real (modelos locais/free lentos demais)

Se o subagente tivesse acesso a tools, =read_file= + descrição seria
rápido. Mas sem tools, o modelo tenta gerar o conteúdo de memória
(e.g., "I can't analyze the file because..."), o que consome tokens
sem resultado.
