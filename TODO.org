** TODO Fix Subagente Órfão (auto-injeção =wait_agent=)
    :PROPERTIES:
    :CREATED: 2026-08-19
    :ASSIGNEE: coder
    :STATUS: active
    :END:

*** Problema

Orquestrador chama =spawn_agent= mas **nunca chama =wait_agent=** para
coletar resultado. Subagente fica órfão e FSM presa em =subagent-waiting=
para sempre. Testado em 2026-08-19 com 5 prompts — 0 chamadas =wait_agent=.

*** Diagnóstico (5 gaps encontrados)

| # | Gap | Severidade | Impacto |
|---|-----|------------|---------|
| 1 | Observer callback espera 2 args, upstream chama com 1 | Crítico | Observers nunca captam resultados |
| 2 | =turn-start-sink= definido mas nunca registrado | Crítico | Resultados formatados mas nunca consumidos |
| 3 | Sem auto-continuação pós-subagente | Crítico | FSM presa em =subagent-waiting= |
| 4 | Advice em =agent-shell--send-command= só dispara em input do usuário | Crítico | Contexto injetado nunca chega ao modelo |
| 5 | Diretiva é advisory, modelos pequenos ignoram | Médio | Modelo encerra turno sem =wait_agent= |

*** Solução: 3 Camadas

**** Camada 1 — Correção de Bugs (obrigatório)

1. *Corrigir observer* (=custom-magent-fsm.el:113=):
   - Callback espera =(lambda (observed-job new-status) ...)=
   - Upstream chama com 1 arg =(funcall (cdr entry) job)=
   - *Fix:* mudar para 1 arg, extrair status do job:
     #+BEGIN_SRC elisp
     (lambda (observed-job)
       (let ((new-status (magent-agent-job-status observed-job)))
         (when (memq new-status '(completed failed))
           ...)))
     #+END_SRC

2. *Registrar =turn-start-sink=* (=custom-magent-fsm.el=):
   - Adicionar =(magent-lifecycle-events-add-sink #'+carlos/magent-fsm-turn-start-sink)=
   - Função existe (line 486) mas nunca é chamada como lifecycle sink

**** Camada 2 — Auto-Injeção (robustez)

3. *Auto-injeção pós-spawn* (=custom-magent-fsm.el=):
   - Após =spawn_agent= retornar, registrar flag =+carlos/magent-fsm-pending-wait=
   - No =turn-end-sink=, se flag ativa e há jobs rodando, injetar =wait_agent=
   - Nova função =+carlos/magent-fsm-inject-wait-after-spawn= (advice :around em =magent-tools--spawn-agent=)

4. *Auto-continuação pós-subagente* (=custom-magent-fsm.el=):
   - Quando subagente completar e FSM em =subagent-waiting=:
     a. Coletar resultado via observer (agora corrigido)
     b. Formatar em =pending-context-messages=
     c. Automaticamente enviar mensagem ao orquestrador com resultado
   - Nova função =+carlos/magent-fsm-auto-resume-on-subagent-complete=

**** Camada 3 — GUI Informativa (usabilidade)

5. *Mensagem de espera melhorada* (=custom-magent-ui.el=):
   - Atual: =[13:52:20] ⏳ ⠴ aguardando subagente...=
   - Novo: =[13:52:20] ⏳ ⠴ aguardando subagente (explore) — modelo: gemma-4-e2b-it-4bit — timeout: 280s=
   - Mostrar nome do agente, modelo e timeout restante

*** Fluxo Corrigido (antes vs depois)

**** Antes (bugado)
#+BEGIN_EXAMPLE
Usuário: "delegue para explore..."
  → spawn_agent(explore) → Job running
  → Orquestrador: "Tarefa delegada, aguardando..."
  → [PAROU — nunca chama wait_agent]
  → FSM: subagent-waiting (para sempre)
  → GUI: "⏳ aguardando subagente..." (loop infinito)
#+END_EXAMPLE

**** Depois (corrigido)
#+BEGIN_EXAMPLE
Usuário: "delegue para explore..."
  → spawn_agent(explore) → Job running
  → Flag pending-wait = t
  → turn-end-sink detecta flag + job rodando
  → Auto-injeta wait_agent(job_id)
  → wait_agent retorna resultado
  → Resultado injetado no próximo turno
  → Orquestrador sintetiza resposta
  → FSM: idle
#+END_EXAMPLE

* Backlog — Features

** TODO D5. Context Sharing Dinâmico para Subagentes
    :PROPERTIES:
    :CREATED: 2026-08-18
    :ASSIGNEE: coder
    :STATUS: backlog
    :END:

*Problema:* subagentes recebem apenas o prompt raw do orquestrador. Não
recebem: histórico de conversa do pai, arquivos lidos/editados, decisões
tomadas na sessão, nem o estado acumulado do orquestrador. Isso obriga o
orquestrador a repetir contexto no prompt (gastando tokens) ou o subagente
trabalha às cegas.

*Solução:* coletar contexto dinâmico do orquestrador (arquivos tocados,
ações recentes, estado do projeto) e injetar automaticamente no prompt
do subagente antes de delegar. Abordagem: enrich do =user-prompt= no
=+carlos/magent-subagent-apply-profile= (não modifica upstream).

** TODO D11. Pipeline de Documentação via Chat (Logic Extractor + Tech-Writer)
    :PROPERTIES:
    :CREATED: 2026-08-18
    :ASSIGNEE: planner
    :STATUS: backlog
    :TAGS: :magent:tools:
    :END:

*Contexto:* orquestrador deve reconhecer intenção do usuário ("explica o que X
faz", "documenta esse módulo", "analisa as regras de negócio") e acionar
pipeline de dois estágios automaticamente (sem keybinding).

*Pipeline:*
1. Orquestrador lê arquivo (=read_file=);
2. =spawn_agent('logic-extractor', código)= → extrai JSON com regras de negócio;
3. =wait_agent= → recebe JSON;
4. =spawn_agent('tech-writer', JSON + instrução Org)= → converte para =.org=;
5. =wait_agent= → recebe documentação;
6. Sintetiza ≤3 bullets para o usuário; oferece salvar =.org= se solicitado.

*Abordagem:*
- Novo perfil =logic-extractor= em =+carlos/magent-subagent-profiles=
  (:min-tier "free") — analista de código, não refatora, não testa,
  apenas traduz código imperativo → regras declarativas (JSON).
- Instrução dedicada =+carlos/magent-logic-extractor-instruction=:
  schema JSON com =modulo=, =proposito=, =pre_condicoes=, =regras=,
  =side_effects=.
- Instrução =+carlos/magent-tech-writer-instruction= ajustada para
  receber JSON e produzir =.org= válido (=* Modulo= → =** Propósito= →
  =** Regras= → =** Efeitos Colaterais=).
- Regra 12 em =+carlos/magent-system-directives=:
  "When user asks to 'document', 'explain what this does', or 'analyze
  business logic': spawn logic-extractor, wait, spawn tech-writer, wait,
  synthesize ≤3 bullets."
- Sem keybinding — ativação 100% via chat natural.

*Critério de saída:* =just compile= zero-warning; 3 testes ERT novos
(perfil logic-extractor registrado, instruções não-vazias, regra 12
presente nas directives); =just test-all= verde; teste interativo com

*Arquivos:* =lisp/custom-magent-subagent.el=, =lisp/custom-magent-tools.el=,
