* Visão Geral

Configuração modular do Emacs baseada no template *Emacs Bedrock*, sem Evil
mode, com IA unificada via =Magent= (agente nativo Emacs-Lisp de codificação com 15 ferramentas e frontend =agent-shell=) e =gptel= (transporte multi-backend), integrada ao NixOS via Home Manager.

- **Framework:** Emacs Bedrock (use-package nativo, Emacs 29+)
- **Sem Evil:** keybindings 100% nativos com prefixo =C-c=
- **IA Nativa & Agentes:** Magent (15 tools, agent-shell UI, skills) + gptel (OpenCode Zen, Claude, Gemini, Ollama Local, MLX Local)
- **Automação Local (CPU/Offline):** Commit IA instantâneo, triagem de logs de teste (=just triage=), gerador local de docstrings/testes (=C-c c d=/=C-c c t=) e gerador de documentos Org RAG (=bin/rag-convert=)
- **42 School:** header42.el + custom-norminette.el (JSON-based, eglot chain) + reformatter C 42
- **Dashboard:** Estilo Nano Emacs (minimalista, tipografia premium)
- **Arquivos:** Dirvish (13 extensões consolidadas), ibuffer, TRAMP otimizado

* Instalação

** Via Nix (Home Manager)

#+begin_src shell
dsw  # darwin-rebuild switch --flake .#agnes
#+end_src

O wrapper =emacs-vanilla= é criado automaticamente.

** Manual

#+begin_src shell
git clone git@github.com:carlosalbertofilho/MyEmacs.git ~/.config/emacs-vanilla
emacs --init-directory ~/.config/emacs-vanilla
#+end_src

** Sync para teste

#+begin_src shell
# No repo de trabalho
git add -A && git commit -m "msg" && git push

# No dir de teste
cd ~/.config/emacs-vanilla && git stash && git pull && git stash pop
#+end_src

** Compilar vterm (primeira vez, GUI)

#+begin_src
M-x vterm-install
#+end_src

** Compilar pdf-tools (macOS, primeira vez)

#+begin_src shell
cd ~/.config/emacs-vanilla/elpa/pdf-tools-*/
./autogen.sh
./configure --bindir=$(pwd)/build/server
make
#+end_src

Depois configurar em =custom-org.el=:
#+begin_src emacs-lisp
(setq pdf-info-epdfinfo-program
      (expand-file-name "build/server/epdfinfo" pdf-tools-directory))
#+end_src

* Recursos Recentes de Dev, IA & UX

- **Plataforma Magent (Agente Nativo Emacs-Lisp):** Agente de codificação com 15 ferramentas nativas de inspeção e edição de código, controle de permissões por agente e frontend =agent-shell= (=C-c M m=).
- **Commit IA Local Offline (=C-c C-g=):** Geração instantânea (<0.5s) e offline de mensagens de commit padronizadas utilizando o modelo `qwen2.5-coder:1.5b` local via Ollama.
- **Triagem Inteligente de Logs (=just triage=):** Script `bin/log-triage` que consome erros de compilação/testes e utiliza a IA local para gerar um relatório RAG de 15 linhas (sem consumir tokens de nuvem).
- **Docstrings & Testes On-Demand (=C-c c d= / =C-c c t=):** Funções Elisp que injetam docstrings PEP 257 / Doxygen e esqueletos de testes unitários diretamente sob o cursor via `qwen2.5-coder:3b`.
- **RAG Document Converter (=bin/rag-convert=):** Script local que converte PDFs, HTML e Markdown em arquivos Org-Mode padronizados para a pasta `docs/`.
- **Guias de Indentação Modernas:** `indent-bars` com stipples de alta performance, escopo inteligente via Tree-sitter e harmonização com temas `ef-themes`.
- **Aninhamento & Parênteses:** `rainbow-delimiters` ativado em todos os modos de programação para diferenciação visual de profundidade de blocos.
- **Linha Atual & Caracteres Invisíveis:** `hl-line-mode` nativo para destaque da linha ativa e `whitespace-mode` sutil.
- **Diagnósticos Inline VS Code:** Sublinhados ondulados nas faces `flycheck-error/warning/info`, mensagens no final da linha via `flycheck-inline` e indicadores na `left-fringe`.
- **Autocomplete & Hover Docs:** Ícones visuais no popup do Corfu via `nerd-icons-corfu` e cartões flutuantes de documentação via `eldoc-box`.
- **Navegação Dirvish-Side:** Abertura de arquivos via `dirvish-side-open-file-action 'reuse`.
- **Task Runners (Just & Makefile):** `justl` (`C-c j`) para receitas de Justfile e `makefile-executor` (`C-c m`/`C-c M`) para alvos interativos de Makefile.
- **Format-on-Save Assíncrono:** `apheleia` ativado globalmente (inibido em C/C++ para preservar o `c_formatter_42`).

* Norminette Integration

A integração com a Norminette da 42 School foi reimplementada:

- **JSON output:** Usa =-f json --no-colors= (parsing confiável)
- **Buffer check:** =M-x custom-norminette-check-buffer= (verifica sem salvar)
- **Contextual hints:** 20+ erros com dicas contextuais
- **Eglot chain:** eglot (clangd LSP) → norminette (style checker)
- **Error levels:** Error → flycheck error, Notice → flycheck warning
