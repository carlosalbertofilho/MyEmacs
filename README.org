* Visão Geral

Configuração modular do Emacs baseada no template *Emacs Bedrock*, sem Evil
mode, com IA unificada via =gptel=, integrada ao NixOS via Home Manager.

- **Framework:** Emacs Bedrock (use-package nativo, Emacs 29+)
- **Sem Evil:** keybindings 100% nativos com prefixo =C-c=
- **IA:** gptel + gptel-agent + SuperChat + MCP (OpenCode Zen, Claude, Gemini, Ollama, MLX Local)
- **42 School:** header42.el + custom-norminette.el (JSON-based, eglot chain)
- **Dashboard:** Estilo Nano Emacs (minimalista, tipografia premium)
- **Arquivos:** Dirvish (13 extensões consolidadas), ibuffer, TRAMP otimizado

* Instalação

** Via Nix (Home Manager)

#+begin_src shell
dsw  # darwin-rebuild switch --flake .#agnes
#+end_src

O wrapper =emacs-vanilla= é criado automaticamente.

** Manual

#+begin_src shell
git clone git@github.com:carlosalbertofilho/MyEmacs.git ~/.config/emacs-vanilla
emacs --init-directory ~/.config/emacs-vanilla
#+end_src

** Sync para teste

#+begin_src shell
# No repo de trabalho
git add -A && git commit -m "msg" && git push

# No dir de teste
cd ~/.config/emacs-vanilla && git stash && git pull && git stash pop
#+end_src

** Compilar vterm (primeira vez, GUI)

#+begin_src
M-x vterm-install
#+end_src

** Compilar pdf-tools (macOS, primeira vez)

#+begin_src shell
cd ~/.config/emacs-vanilla/elpa/pdf-tools-*/
./autogen.sh
./configure --bindir=$(pwd)/build/server
make
#+end_src

Depois configurar em =custom-org.el=:
#+begin_src emacs-lisp
(setq pdf-info-epdfinfo-program
      (expand-file-name "build/server/epdfinfo" pdf-tools-directory))
#+end_src

* Recursos Recentes de Dev & UX

- **Guias de Indentação Modernas:** `indent-bars` com stipples de alta performance, escopo inteligente via Tree-sitter e harmonização com temas `ef-themes`.
- **Aninhamento & Parênteses:** `rainbow-delimiters` ativado em todos os modos de programação para diferenciação visual de profundidade de blocos.
- **Linha Atual & Caracteres Invisíveis:** `hl-line-mode` nativo para destaque da linha ativa e `whitespace-mode` sutil (exibindo apenas espaços desnecessários no fim de linha e tabulações).
- **Diagnósticos Inline VS Code:** Sublinhados ondulados nas faces `flycheck-error/warning/info`, mensagens no final da linha via `flycheck-inline` e indicadores na `left-fringe`.
- **Autocomplete & Hover Docs:** Ícones visuais de tipo no popup do Corfu via `nerd-icons-corfu` e cartões flutuantes de documentação ao lado do cursor via `eldoc-box`.
- **Navegação Dirvish-Side:** Abertura de arquivos via `dirvish-side-open-file-action 'reuse` (reaproveita com precisão a janela principal de código de onde a sidebar foi aberta).
- **Task Runners (Just & Makefile):** `justl` (`C-c j`/`C-c J`) para receitas de Justfile e `makefile-executor` (`C-c m`/`C-c M`) para alvos interativos de Makefile.
- **Tree-Sitter & Nix:** Integração automatizada dos diretórios do Nix Store (`/nix/store/*-emacs-treesit-grammars`, `~/.nix-profile`) com fallback gracioso e compilação nativa no `just compile`.
- **Format-on-Save Assíncrono:** `apheleia` ativado globalmente (inibido em C/C++ para preservar o `c_formatter_42` da Norma 42).
- **Gavetas Inferiores Nativas:** Regras centralizadas em `display-buffer-alist` para compilação, eglot events, magit, vterm, eshell e gptel.

* Norminette Integration

A integração com a Norminette da 42 School foi reimplementada:

- **JSON output:** Usa =-f json --no-colors= (parsing confiável)
- **Buffer check:** =M-x custom-norminette-check-buffer= (verifica sem salvar)
- **Contextual hints:** 20+ erros com dicas contextuais
- **Eglot chain:** eglot (clangd LSP) → norminette (style checker)
- **Error levels:** Error → flycheck error, Notice → flycheck warning
